# Portfolio Ultimate

A modern, minimalist developer portfolio built with **React**, **Vite**, and clean **CSS variables**. Designed with high visual contrast, responsive layout grids, dark/light theme switching, and dedicated project detail views.

---

## 🌟 Key Features

* 🌓 **Dark & Light Mode Toggle**: Seamless theme switching with state persistence in `localStorage`.
* 🎨 **Minimalist Design System**: Ultra-clean monochrome aesthetic with high-contrast typography and subtle borders.
* 🔍 **Dedicated Project Detail View**: In-depth project page showcasing system architecture, zero-trust security gates, deployment stack, and live repository links.
* 💼 **Interactive Work History**: Tabbed experience section detailing company roles, dates, locations, and achievements.
* 🛠️ **Categorized Tech Stack Matrix**: Organized domain breakdown (Frontend, Backend, Databases, Tools) with official site links.
* 🎓 **Education & Certifications**: Verified credentials grid featuring CompTIA, AWS Academy, and academic honors.
* 💬 **Quick Contact Drawer**: Floating bottom-right quick messaging and email copy utility.
* 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile viewports.

---

## 🛠️ Tech Stack

* **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
* **Icons**: [Lucide React](https://lucide.dev/)
* **Styling**: Vanilla CSS Modules with custom theme variables

## 🚀 Getting Started

### Prerequisites
Make sure you have **Node.js** (v18+) installed.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ennonn/Portfolio-Ultimate.git
   cd Portfolio-Ultimate
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` or `http://localhost:5174/` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## ✏️ Customizing Portfolio Information

All portfolio text, projects, experience, tech stack, and certifications are centralized in a single file:
`src/data/portfolioData.js`

Edit `portfolioData.js` to update:
- Personal details, bio, and social links
- Project titles, descriptions, screenshots, and live URLs
- Work history and bullet points
- Tech stack categories and certifications
